# Stream Recorder Pro

Browser extension (Brave / Chrome) that records what a streaming site does — requests, API replies, scripts, page and iframe HTML — and exports it as JSON, so NovaPlay extractors and resolvers can be built from real captures.

**How to install, record, export and what to send: [docs/GUIDE.md](docs/GUIDE.md)**

Quick start: `brave://extensions` → Developer mode → **Load unpacked** → pick this folder. After every update, click **reload** on the extension card.

Related: [NovaPlay](https://github.com/westy4ever/novaplay-modular) and its [Site Test Guide](https://github.com/westy4ever/novaplay-modular/blob/main/docs/SITE_TEST_GUIDE.md).
